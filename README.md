# One Line, One Chill

One line. One chill. The scariest horror sentence I could write in a single line.

> My mother called me down for dinner, but my mother died three years ago — and the voice is getting closer.

Run `python3 main.py` and it writes the entry to `/output/entry.txt`. Python standard library only.
